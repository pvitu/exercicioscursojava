Calculadora de Geometria Plana - Retângulo

Este é um projeto simples em Java para calcular a área, o perímetro e a diagonal de um retângulo com base nas medidas de largura e altura fornecidas pelo usuário.

FuncionalidadesO projeto é composto por duas classes principais:Retangulo.java: Contém a lógica de negócio (atributos e métodos) 
para realizar os cálculos.Main.java: Contém a lógica de entrada/saída de dados, lendo as dimensões do retângulo e exibindo os resultados.

💻 Exemplo de UsoAo rodar o programa, você verá a seguinte interação no console (exemplo com largura 50 e altura 50):Entre com a altura e largura do retângulo:
Largura (Width): 
50
Altura (Height): 
50

DIAGONAL = 70.71
