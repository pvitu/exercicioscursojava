# 📚 Exercícios de Java e Programação Orientada a Objetos (POO)

Este repositório contém os exercícios resolvidos e implementações práticas realizadas por mim durante o curso **"Java Completo 2023: Programação Orientada a Objetos + Projetos"**, ministrado pelo Professor **Nelio Alves** na Udemy.

O objetivo deste repositório é registrar e demonstrar o aprendizado e a aplicação dos conceitos de Java, desde a sintaxe básica até o desenvolvimento de lógica com Programação Orientada a Objetos.

---

## 🎯 Conteúdo e Habilidades Desenvolvidas

Os exercícios estão organizados por módulos ou temas principais do curso. Cada pasta representa um conjunto de problemas ou um projeto específico.

| Módulo/Pasta | Foco Principal | Habilidades Praticadas |
| :--- | :--- | :--- |
| `salariofuncionario` | POO (Classes e Métodos) | Criação de classes, métodos de negócio, `toString()` e manipulação de entrada (`Scanner`). |
| `retangulo` | POO (Classes) e Estruturas | Cálculo de área, perímetro e diagonal de entidades geométricas. |
| `curso_produtoseestoque` | POO e Encapsulamento | Implementação de construtores, *getters* e *setters* e lógica de estoque (`adicionarProdutos`, `removerProdutos`). |
| `Exercicio loop for - incremento` | Estruturas de Repetição | Utilização de `for`, `while` e `do-while` para repetição controlada. |
| `Exercicio média do aluno` | Estruturas Condicionais | Aplicação de `if/else` e lógica booleana para tomada de decisão (aprovação/reprovação). |
| `Exercicios 01` e `02` | Sintaxe Básica e Variáveis | Operadores, tipos primitivos, `System.out.println` e entrada de dados simples. |
| `.gitignore` | Ferramentas de Desenvolvimento | Configuração de exclusão de arquivos de IDE (`.class`, `.idea`, etc.) para manter o repositório limpo. |
